# REE Conference Tracker 2026-27

A single-page tracker of rare earth, magnet and critical minerals conferences for 2026 and 2027, with live countdowns, a monthly chart, a searchable table and a list of annual events whose 2027 dates are still pending.

- `index.html` is the whole site (no build step).
- Deployed on Netlify from the `main` branch.
- To update: edit the `EVENTS` or `TBC` arrays in `index.html` and push.
